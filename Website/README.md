# St. Stephen Parish Website

## Overview
This is the official website for St. Stephen Parish in Darkuman, Accra. The website provides information about the parish, including mass schedules, ministries, parish groups, gallery, and contact information.

## Features
- Responsive design that works on desktop and mobile devices
- Information about the parish history and mission
- Mass and confession schedules
- Details about parish groups and ministries
- Photo gallery of parish events and activities
- Contact form for inquiries
- Parish bulletin with weekly announcements

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome for icons

## Pages
- **Home**: Welcome page with key information and announcements
- **About Us**: Information about the parish history, mission, and vision
- **Mass Schedule**: Times for masses, confessions, and other liturgical services
- **Parish Groups**: Information about various ministries and societies
- **Gallery**: Photos from parish events and activities
- **Contact**: Contact information and inquiry form
- **Bulletin**: Weekly parish bulletin with announcements

## Setup
To run this website locally:
1. Clone the repository
2. Open index.html in your web browser
